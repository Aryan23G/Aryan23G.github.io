Project demo · SentinelDesk

An AI assistant for the IT help desk

Every company's IT team gets hundreds of help requests, and some of them are scams pretending to be real requests. SentinelDesk reads each one, checks it for warning signs, decides how urgent it is, and sends it to the right team. Pick a message on the left to watch it work.

STEP 01

A request comes in

Someone emails IT: a forgotten password, a broken printer, or a scam made to look like one of those.

STEP 02

Claude investigates

An AI agent decides which of five tools to use, from scanning for scam tricks to looking up help articles. You see every call live.

STEP 03

Rules have the final word

It sets urgency, routing and a reply. Then fixed rules check that decision and overrule the AI if a message tricked it.

    Agentic AI

    AI that takes actions with tools, step by step, instead of just answering a question.

    About this demo. Tickets are sent to the SentinelDesk server (TypeScript, Express), where Claude investigates them with five tools and submits a decision. A rules-based guardrail then re-checks the raw ticket and overrides the AI on any attack, so a message that fools the model still ends up with the security team. No visitor API key is needed: the server holds it, with rate limits and a daily budget. If the server is asleep or over budget, the same rules engine runs here in your browser instead.

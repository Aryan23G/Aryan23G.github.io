    About this demo. GitHub Pages can't run a server or keep an API key secret, so this page runs SentinelDesk's built-in offline engine: the same security scanner, sender checks, knowledge base and routing rules as the full app, compiled to run in your browser. Nothing you type is sent anywhere. In the full Node/Express app, a Claude tool-use loop calls these same tools, and the rule-based guardrail can override the model if a ticket tries to manipulate it.

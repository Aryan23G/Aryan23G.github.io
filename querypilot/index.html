QueryPilot

Ask a business question in plain English and get the SQL, the result and a chart. It's free with no API key: a built-in engine answers in your browser, and a Claude agent takes over if you add your own key. Every query passes a five-layer read-only guard before it reaches the database.

Sample questions · or ask your own

Orbit Outfitters is a made-up online outdoor-gear store with two years of orders (2024 to 2025): customers, products, orders, line items and reviews.

Ask your own question: it's free, with no API key needed. The built-in local engine turns it into SQL in your browser, including growth, retention, top-per-group and share questions, and runs it through the same safety pipeline. Optionally add an Anthropic API key to use the Claude agent for follow-ups and free-form exploration.

Engine

Without a key, questions are answered by the free local engine: a deterministic NL→SQL parser that runs entirely in your browser. A key switches to the Claude agent.

Your key stays in this browser tab (sessionStorage) and is sent only to api.anthropic.com. There is no backend.

Safety layers

  1. Static guardTokenizer-based: one statement, SELECT/WITH only, no write or DDL keywords, no risky functions, table allowlist.
  2. Bytecode checkCompiles with EXPLAIN and inspects SQLite's VDBE program: no write opcodes or write transactions, and reads only from allowlisted b-trees.
  3. Read-only connectionPRAGMA query_only makes SQLite itself refuse writes.
  4. Resource limitsRow cap while stepping, and a 4s timeout that kills and restarts the worker.
  5. SandboxIn-memory database rebuilt from a fixed seed. Query results go to the model as data, never as instructions.

PII shield. Customer names and emails are swapped for placeholders (CUSTOMER_NAME_12) in everything sent to Claude, then mapped back to real values just before the SQL runs and before you see the answer.

Text-to-SQL analytics

QueryPilot

Ask a business question in plain English and get the SQL, the result and a chart. It's free and needs no API key or account: a built-in engine turns your question into SQL right in your browser, and every query passes a five-layer read-only guard before it reaches the database.

  • 1Question
  • 2Query plan → SQL
  • 3Guard + bytecode check
  • 4SQLite in a worker
  • 5Validated chart
Sample questions · or ask your own

Orbit Outfitters is a made-up online outdoor-gear store with two years of orders (2024 to 2025): customers, products, orders, line items and reviews.

Ask your own question about revenue, orders, customers, returns, ratings and more, including growth, retention, top-per-group and share questions. The engine shows how it read your question, the SQL it wrote and the checks it passed. Questions it can't answer reliably, like "why" or forecasts, are declined instead of guessed.

How it works

A deterministic parser reads your question into a query plan: a measure, groupings, filters and ranking. The plan compiles to SQL from a fixed join graph, so filter values always come from the database, never from your text. There is no LLM, no backend and nothing to sign up for.

Safety layers

  1. Static guardTokenizer-based: one statement, SELECT/WITH only, no write or DDL keywords, no risky functions, table allowlist.
  2. Bytecode checkCompiles with EXPLAIN and inspects SQLite's VDBE program: no write opcodes or write transactions, and reads only from allowlisted b-trees.
  3. Read-only connectionPRAGMA query_only makes SQLite itself refuse writes.
  4. Resource limitsRow cap while stepping, and a 4s timeout that kills and restarts the worker.
  5. SandboxIn-memory database rebuilt from a fixed seed, so there is nothing real to damage.
